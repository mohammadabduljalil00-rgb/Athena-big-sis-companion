
# Athena AI — Dual Screen

Athena is an ESP32 AI companion with a synchronized Chrome interface.

## Features
- ESP32 handheld interface
- Chrome laptop interface
- USB Serial communication
- Permission-controlled connection
- Synchronized moods and messages

## Setup

1. Upload the Athena ESP32 firmware.
2. Open the GitHub Pages website in Chrome.
3. Connect the ESP32.
4. Click Connect Athena via USB.
5. Select the ESP32 serial port and grant access.

## Requirements
- Google Chrome or Microsoft Edge desktop
- ESP32-WROOM
- USB data cable
- Firmware using the Athena JSON protocol

## Enable GitHub Pages

Repository Settings → Pages → Deploy from a branch → main → / (root).

The website will be available at:

https://YOUR-GITHUB-USERNAME.github.io/Athena-AI/
